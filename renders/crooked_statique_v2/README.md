# Crooked Cavern — trois layouts STATIQUES

Cette version corrige l’ajout d’animation non demandé. **Aucune particule, aucune animation, aucun GIF/WebP dans ce pack.** Les anciennes versions restent uniquement en historique.

- [01 : entrée centrale](01/composition.png)
- [02 : entrée à gauche](02/composition.png)
- [03 : entrée à droite](03/composition.png)

Chaque dossier possède quatre PNG 320×240 alignés : sol/chemin, paroi, rochers, végétation. La galerie `apercu_northern_calques_v1.html` permet de les masquer et de les exporter individuellement.

Les motifs de roche sont ceux de Crooked Cavern recolorés en gris dans le pack précédent, à leur échelle native. Pour les variantes 02/03, entrée et chemin sont décalés de −24/+24 pixels par rapport à la variante 01, les blocs sont repositionnés et les bandes aux extrémités sont complétées. Ce sont des modifications légères du layout, pas trois nouveaux matériaux rocheux. Les touffes générées restent séparées de la roche canonique. Les raccords de bandes aux limites restent à valider artistiquement.

Les trois recompositions sont vérifiées exactement. Source et recoloration documentées dans `renders/crooked_verdure_v1/README.md`. Aucun fichier `.rsground` ou mod natif modifié, pas de validation en jeu.
