# Clairière — falaise de glace, forêt en contrebas et ciel nocturne

Cette version reprend le layout simple de `glacier_cliff_aurora_v9` et le
transforme sans recréer l'ancienne arène :

- clairière ouverte sur le plateau supérieur ;
- bord de falaise en glace bleue/cyan ;
- forêt enneigée visible plus bas sous la falaise ;
- montagnes lointaines derrière la lisière ;
- calque ciel séparé avec ciel nocturne, lune, nuages et aurore canonique.

Rendu final :

`final_clairiere_falaise_glace_foret_sky.png`

Calque ciel :

`layers/01_sky_moon_clouds_aurora_magenta.png`

Le magenta du calque ciel est uniquement une clé de masque. Les références
canoniques utilisées sont `pmdskyicearena.png`, `iceroadpmdsky.png`,
`snow.png`, `bgnightbackgroundpmdskyda.png`, `aurorepmdsky.png` et
`nuit_03_nuages.png` pour la lune et les nuages.
