# Glacier Cliff Aurora v7 — composition pixel-art générée

Composition finale générée depuis zéro avec le générateur d'image en utilisant
les références canoniques et le tileset `VastIceMountain.tile` comme références
de matière et de style.

La scène contient : ciel nocturne, aurore indépendante, montagnes distantes,
forêt enneigée en contrebas, falaise d'arène, plateau glacé praticable et
chemin d'accès sud. Les sources n'ont pas été collées : elles ont servi de
références au redessin pixel-art unifié.

Cette image est une composition visuelle de layout. La map PMDO jouable reste
construite avec le vrai `.tile`, les `.dir` et le `.rsground`; cette image ne
remplace pas ces ressources natives.
