# Rendus et Planches — Sprites de Pond Métano pour Falaises

Ce dossier rassemble les documents de synthèse visuelle et scènes de démonstration :

- **`PLANCHE_SPRITES_POND_CLIFF.png`** (1000 × 720 px) : Planche d'ensemble légendée présentant les 5 modules d'étangs, le tileset modulaire 24×24, la scène d'intégration sur falaise et le guide technique PMDO.
- **`METANO_CLIFF_TERRASSE_POND_EXEMPLE.png`** (256 × 224 px) : Scène de démonstration montrant un étang de terrasse avec alcôve, cascade amont, pierres de gué, chemin herbeux et plongée vers le vide en contrebas.
- **`METANO_CLIFF_TERRASSE_POND_EXEMPLE.gif`** : Version animée en boucle à cadence native PMDO (10 ticks / 167 ms).
- **`METANO_CLIFF_TERRASSE_POND_EXEMPLE.tile`** : Fichier binaire PMDO prêt pour l'éditeur.

Pour l'ensemble des sprites individuels, calques transparents et fichiers `.tile` / `.tsj`, consultez le dossier `sprites/pond_metano_cliffs/`.
