# Propositions générées mises de côté

Les dix planches dans `bruts/` contiennent des propositions de nouvelles compositions produites avant la dernière correction de l’utilisateur. Elles ne sont **pas validées**, pas exportées comme zones finales et pas utilisées pour le lot fidèle.

L’utilisateur demande ensuite de reproduire les layouts de référence, en plusieurs calques, avec seulement des changements subtils. La livraison qui applique cette demande est **`renders/references_fideles_v1/`**, galerie `apercu_references_fideles_v1.html`.

Ces recherches sont conservées pour ne pas perdre le travail, mais ne doivent pas être annoncées comme20 donjons livrés ou comme des textures natives identiques aux références.
