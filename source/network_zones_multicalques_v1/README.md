# Réseau de zones — entrées/fonds multicalques

Cette livraison reprend les références du commit `d5c79863a63abfb39f68f80adf85ae4c061ed3bd` et les organise zone par zone, dans le modèle des duos : fond biome, terrain, entrée séparée et cadre/layout.

Les intérieurs ont une composition ronde ou ovale plutôt qu'un rectangle carré. Les scènes sombres/noir-blanc sont attribuées à des biomes explicites : grotte glacée/roche bleue, ruines blanches et forêt sinistre.

Les fichiers sont des couches d'édition distinctes, prêtes à être remplacées ou enrichies par les calques moteur PMDO sans fusionner l'entrée avec le fond.
