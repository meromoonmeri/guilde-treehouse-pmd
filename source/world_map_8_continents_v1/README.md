# Carte à 8 continents — fond orange canonique

La carte reprend le fond orange de `Explorers_of_Sky_-_World_Map.png` et place dessus un unique calque de composition contenant huit continents et leurs lieux.

## Deux calques

- `00_fond_canonique_orange.png` : fond orange canonique seul, sans ajout ;
- `01_8_continents_et_lieux.png` : continents, îles, biomes et lieux dessinés directement ensemble.

Composition : `WorldMap_8_Continents_Orange_DA.png`.

## Continents

Volcan, Marais, Sylve, Dunes, Lacs, Aurore, Sakura et Tropiques. Le calque foreground comprend également les cascades, le portail, la tour en ruine dans les nuages, les donjons et les marqueurs organiques.

La composition foreground est générée dans le style strict de la référence. Elle est documentée comme création guidée, pas comme extraction de pixels natifs. Le fond orange canonique reste séparé et intact.
