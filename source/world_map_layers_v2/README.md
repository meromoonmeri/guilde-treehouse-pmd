# Carte DA stricte — deux calques

Cette version suit la correction demandée : exactement deux calques statiques assemblables.

1. `00_fond_canonique_sans_motifs.png` : fond issu de `Explorers_of_Sky_-_World_Map.png`, agrandi en nearest-neighbor 2×, sans continents ni lieux ajoutés.
2. `01_continents_et_lieux_dessines.png` : unique calque de premier plan généré avec les continents, les îles et les lieux dessinés directement dans la même DA.

Composition : `renders/world_map_layers_v2/WorldMap_7Continents_DA_Strict.png`.

Le premier plan comprend notamment :

- sept continents et plusieurs îles ;
- Reverie Town avec arbre-monde et cascades, sans architecture humaine classique ;
- sanctuaire Sakura ;
- portail des îles flottantes ;
- tour en ruine dans les nuages ;
- zone volcanique et portail de donjon ;
- observatoire enneigé ;
- village de marais ;
- ruines anciennes et îlots côtiers.

Les motifs du premier plan sont générés par image-guidée à partir de la référence canonique et sont documentés comme composition nouvelle, pas comme pixels natifs. Le fond canonique reste séparé et intact.
