# Sources de zones — texture Treasure Town

Ces sources correspondent à la correction demandée : nouveaux layouts, plans générés séparément, texture de roche de Treasure Town et eau destinée au palette cycling.

Les polygones des guides définissent uniquement les dispositions. Les dessins proviennent du générateur : quatre terrains, trois décors de fond, une banque d’eau, une banque de végétation et un matériau d’eau. Les références d’origine n’ont pas été simplement nettoyées de leurs bâtiments.

Les plans retenus sont normalisés au plus proche voisin et détourés sur magenta. L’animation par palettes est une étape séparée, construite à partir de ces éléments. Les falaises de guilde/côtière existantes ne servent que de comparaison et restent inchangées.

La planche de texture est dérivée des graphismes de Treasure Town présents dans Minemaker0430/ExplorersOfSkyOrigins au commit b8c0de576606c5a24802158462d5d1d7e561f72d. Elle est une référence tierce, pas une illustration originale de ce pack.
