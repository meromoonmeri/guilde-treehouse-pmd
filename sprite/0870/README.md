# Falinks #0870 — forme 0 (formation complète)

Dossier multi-sheet SpriteCollab/SpriteBot, importable dans PMDO via
**Char Sprites > Import**.

La forme 0 de Falinks n'existait pas en amont : seules les sous-formes
**0002 Brass** et **0003 Trooper** sont publiées. La forme 0 est l'escouade
entière, composée à partir de leurs pixels canoniques — Brass en tête de
colonne, trois Troopers derrière, sans recoloration ni rééchantillonnage.

12 animations : Walk, Attack, Strike, Shoot, Sleep, Hurt, Idle, Swing, Double,
Hop, Charge, Rotate. Palette partagée de 13 couleurs.
