# Prototype dessiné au générateur

`falaise_metano_generateur.png` est le dessin demandé lors de l'étape précédente, guidé par les références canoniques. Il mesure 1200 × 896 px. C'est une image générée, pas un assemblage garanti de tuiles originales.

Il n'est **pas utilisé comme texture** dans le nouveau pack pixel-perfect. Pour les layouts faits de tuiles sources, avec versions sans eau/sans chemins et quatre phases d'eau, utiliser `../metano_pixel_perfect/`.
