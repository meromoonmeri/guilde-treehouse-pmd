Objets séparés

Chaque sprite dispose aussi de son PNG individuel, d’un pivot et d’une entrée dans Tiled.

Cliquer dans le parquet pour déplacer le motif sur la grille. C’est une démonstration ; aucun fichier de salle n’est modifié.

Les retours utilisent le même bois ambré. 47 configurations de voisinage sont rangées dans un atlas de 48 cases ; la dernière est réservée.

Les ombres sont une autre planche : elles longent les parois sans fermer les passages.

Les règles de voisinage sont documentées dans les métadonnées du kit.
